# Berojgar's Notes 📚

> A simple and organized web platform designed to store, access, and share study notes.

🔗 **Live Demo:** [https://berojgardev.github.io/Berojgars-Notes/](https://berojgardev.github.io/Berojgars-Notes/)

---

## 🌟 About The Project

**Berojgar's Notes** is my first completed web development project. It was built to solve the hassle of organizing and accessing study materials in one clean, lightweight web interface. 

---

## ✨ Features

- **Clean Layout:** Easy-to-read interface optimized for browsing notes.
- **Fast Access:** Lightweight pages that load instantly.
- **Hosted Live:** Accessible from any device via GitHub Pages.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3
- **Version Control:** Git & GitHub
- **Hosting:** GitHub Pages
